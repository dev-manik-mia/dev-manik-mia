### 📡 [Compel](https://compel.ad) — Advertising for the AI Search Era · *Active*
> An ad-tech platform that helps brands **show up in answers from ChatGPT, Gemini, Perplexity and Claude**. It does this by placing human-written content on the publisher sites those AI models cite.

- **AI visibility mapping:** tracks which domains and narratives each AI engine cites for a brand
- **Publisher marketplace:** 110,000+ publications, with transparent per-placement pricing
- **Campaign management:** goals, monthly budgets and automated dashboards for brands and agencies
- **Attribution:** weekly visibility tracking and measurement of how accurately AI describes the brand
- **Built for fast turnaround:** placements can go live within 24 hours, and agencies get white-label options

`Ad-Tech` `AI Search / GEO` `SaaS` `Marketplace`

### 🕌 [Halal Pages](https://halalpages.co.uk) — UK Halal Discovery Platform · *Latest launch*
> A UK-wide platform helping the Muslim community **discover halal businesses, find mosques and check prayer times** — on the web and in a native mobile app.

- **Business directory** — halal restaurants and vendors with search and category browsing
- **Mosque finder & prayer times** — location-aware community tools
- **Web + mobile, one backend** — Next.js web app and React Native app share a single NestJS API
- **Built to scale** — PostgreSQL for relational data, Redis for caching and hot lookups
- **Self-managed infra** — deployed and operated on an Ubuntu VPS (NGINX, process management, TLS)

`NestJS` `PostgreSQL` `Redis` `Next.js` `TailwindCSS` `React Native` `Ubuntu VPS`
